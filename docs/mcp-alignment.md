# 既有功能与 MCP 的行为对齐

本次基于个人分支 `1586e1f`，对照 `xpzouying/xiaohongshu-mcp` 的 `aad2a3d` 快照，处理已实现功能的结果判定、数据完整性及页面适配。保留 Python CLI、XHS Bridge、扁平列表输出，以及私信、长文、草稿、个人库与导出等自有能力。

## 行为变化

| 对照报告项 | 模块 | 修改后的行为 |
| --- | --- | --- |
| 1 | 点赞、收藏 | 核对当前笔记和真实布尔状态；已达到目标不点击；一次点击后核验，结果不明返回 `status=unknown`，不自动重复切换；不成功时 CLI 退出码为 2。 |
| 3、4 | 评论、回复 | 保留目标评论的 ID 和对象范围，先查已加载项再判断底部，可展开楼中楼；提交前确认一级评论或指定回复模式，提交后核对新出现的己方评论，返回核验证据。旧同文评论不能作为本次成功证据。 |
| 2、5 | 图文、视频发布 | 无可靠成功反馈时返回未确认错误，不再报告发布完成。用户要求原创时，声明设置失败阻止发布。 |
| 14 | 定时发布 | 在页面填写与上传前校验显式时区及未来 1 小时至 14 天窗口，转换为北京时间填写。 |
| 16 | 多图上传 | 后续图片使用图片类型的文件输入框，避免误用其他类型的上传控件。 |
| 6 | 评论读取 | 默认一级评论上限 20；零值和负值也按 20 处理。需要更多时显式指定数量。 |
| 7 | 评论分页 | 保留原 `comments` 数组；新增 `comment_pagination`，说明游标、一级与子评论完整性、限制及停止原因。未知完整性返回 `null`。 |
| 9 | 视频详情与导出 | 保留所有编码桶的媒体流及字幕地址，不硬编码 EF4 等编码名称；仍只导出地址，不下载媒体。 |
| 8 | 用户主页 | 现有 `user-profile` 增加 `--tab note|fav|liked`；只读取请求分组，核对目标和分组，避免将收藏、点赞与笔记混合。 |
| 13 | 首页与搜索 | 只返回 `modelType=note`，保留图文及视频，排除热词、直播卡片。 |
| 12 | 搜索筛选 | 保留实测有效的点击展开方式，按组标签和选项文字定位；核对全部选中状态和加载完成，刷新未确认时不返回旧结果。 |
| 11 | 通知读取 | 新增 `liked`、评论及目标内容状态、`content_available`、`can_reply`。不可用记录保留，缺证据返回 `null`；内容正常不等于有回复入口。 |

`unknown` 表示操作可能已经发生但无法确认，不能据此直接重复发送、发布或切换状态。先读取当前网页或后台核对。`comments_complete` 只有明确为 `true` 才能宣称评论完整；默认数量上限不保证网页恰好每批只加载该数量。

## 范围与验证

本次没有新增尚未实现的通知未读总览、通知内回复/点赞、商品绑定，也未添加全量关注/粉丝列表、已发布笔记编辑删除、专辑创建移动或正文全文检索。

验证使用两类证据：执行真实模块/网页脚本的离线回归，以及已登录网页的只读结构和读取结果。真实页面已核对搜索组合筛选、通知状态读取、点赞与收藏状态解析、评论查找及回复对象绑定、空发布表单的图片输入框。主页三个分组分别读取到 5/5/10 条；视频详情保留 EF4/EF5/EF6/EF7 编码桶及 en-US/source/zh-CN 字幕组，该结果也已通过本地 Markdown 导出。回复入口只打开了空编辑框，没有输入或提交；没有执行真实点赞、收藏、评论、发布、保存或上传。发布结果、原创失败、定时边界和操作中断等变更路径通过隔离测试验证。

各子技能保留业务操作约束。需要使用这些参数时，分别阅读 [社交互动](../skills/xhs-interact/SKILL.md)、[内容发现](../skills/xhs-explore/SKILL.md) 和 [内容发布](../skills/xhs-publish/SKILL.md)。

本次验证结果（2026-09-10）：`python -m pytest -q` 全量 234 项通过；分别执行 `tests/*.test.cjs` 共 73 项通过。改动涉及的 Python 模块与新测试通过 Ruff；`scripts/cli.py` 保留基础分支原有的 9 项检查问题，没有新增。三个子技能的元数据、文档本地链接及差异检查通过。真实网页采样保存在开发环境，不包含在仓库或测试夹具中。
